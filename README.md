# 视频下载（iOS 侧载用）

在 iPhone 上独立运行的视频下载 App，不需要电脑开着。
支持 YouTube、抖音、TikTok、B站、小红书、X（推特），其他网站会尝试从网页里找视频文件。
YouTube 部分基于开源库 [YouTubeKit](https://github.com/alexeichhorn/YouTubeKit)（MIT 许可）；
其他网站的解析思路参考了 [yt-dlp](https://github.com/yt-dlp/yt-dlp)，推特读不到时会用 [FxTwitter](https://github.com/FxEmbed/FxEmbed) 的公开接口。

## 功能
- 粘贴链接 → 自动列出可选格式
- **高画质**（1080p 等）：画面和声音分开下载，手机上自动合并成 mp4
- **快速**：直接下载音视频合一的文件（通常 360p）
- **仅音频**：m4a
- 存到相册、分享、「已下载」列表里直接播放 / 左滑删除
- 文件同时出现在「文件」App →「我的 iPhone」→「视频下载」

## 从分享菜单直接下载（快捷指令）
1. 打开「快捷指令」App → 右上角「＋」新建，命名为「视频下载」。
2. 点底部的 ⓘ（或右上角设置），打开「在共享表单中显示」。
3. 添加操作「URL 编码」，内容选「快捷指令输入」。
4. 添加操作「文本」，内容填 `ytdl://download?url=`，后面插入变量「URL 编码的文本」。
5. 添加操作「打开 URL」，内容选上一步的「文本」。
6. 之后在 YouTube 点「分享」→「更多」→「视频下载」即可。

## 编译 IPA（不需要 Mac）
1. 在 GitHub 新建一个仓库，把这个文件夹里的**全部内容**（包括 `.github` 文件夹）上传上去。
2. 打开仓库的 **Actions** 页面，选 **Build IPA** → **Run workflow**（推送到 main 也会自动编译）。
3. 大约 5～10 分钟后，点进完成的那次运行，在页面底部 **Artifacts** 下载 `YTDownloader-ipa`，解压得到 `YTDownloader.ipa`。
4. 用你平时的侧载工具（Sideloadly / AltStore / SideStore / TrollStore 等）安装。
   生成的 IPA 没有签名，侧载工具会用你的 Apple ID 重新签名。

## 有 Mac 的话
```bash
brew install xcodegen
xcodegen generate
open YTDownloader.xcodeproj
```
在 Xcode 里选自己的 Team，直接装到手机上即可。

## 常见问题
- **解析失败**：多半是 YouTube 改了规则。到 YouTubeKit 的 Releases 看有没有新版本，
  有的话重新跑一次 Actions 就会自动用上新版（`project.yml` 里写的是 `from: 0.4.9`，会取最新的 0.x 版本）。
- **后台下载**：下载时可以切到别的 App 或锁屏。原理是下载期间播放一段无声音频让系统不暂停 App（不会打断你听的音乐），下载完就停。
- **下载慢**：在设置里把「下载线程数」往右拖（1～64），同时开多条连接分段下载；一般 4～16 就够，出现失败就调小再试。
- **合并失败**：改选「快速」格式。
- 本机解析失败时，App 会改用 YouTubeKit 作者提供的远程解析服务器（只发送视频 ID）。

## 注意
YouTube 的使用条款原则上不允许下载视频。请只用于自己的视频、允许下载的内容或个人离线观看，
不要再上传或分发他人的作品。

## 版本号规则
- 修 bug：+0.01（例：1.03 → 1.04）
- 加功能：+0.1（例：1.03 → 1.13）
- 版本号在 `project.yml` 的 `CFBundleShortVersionString`，`CFBundleVersion` 每次 +1
- App 首页底部会显示当前版本

## 各网站说明
- **TikTok**：打开作品网页取无水印地址；图文作品暂不支持。
- **B站**：不登录一般最高 720p（直接下载 mp4）；在「设置」→「登录网站」登录后可下 1080p（画面声音分开下载再合并）。支持 b23.tv 短链接、分 P（链接里的 `?p=2`）。
- **小红书**：分享链接要带 `xsec_token`（直接复制 App 里的分享链接就有）。海外网络常被要求登录，先在「登录网站」登录。图文笔记暂不支持。
- **X（推特）**：先用推特官方嵌入接口，读不到时用 FxTwitter；一条推文有多个视频会分别列出。
- **其他网站**：链接本身是视频文件就直接下载；否则在网页里找 og:video / `<video>` 的 mp4 地址。m3u8 直播流暂不支持。
